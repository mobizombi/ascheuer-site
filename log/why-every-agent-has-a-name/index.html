Why every agent on the team has a name

Every agent on my team has a first name. Chase is chief of staff. Penny is the CFO. There is an analyst, a head of design, an art director, translators for four languages and a QA reviewer who checks every translated page on a phone-sized screen.

I did this half as a joke. It stuck because it solved a real problem.

The problem it solves

When you work with one general assistant, every request lands in the same place and you have to explain the context every time. When you have specialists, the hard part becomes routing: which agent owns this?

A name is a short, unambiguous address. "Ask Penny if this is worth it" carries a whole job description: think in cash, be conservative, say no when the numbers say no. I do not have to restate that. And because each agent has a written role, two of them disagreeing is useful information, not noise.

LESSONThe name is not the point. The written role behind the name is. The name just makes it cheap to use.

The other benefit is accountability. When something ships broken, "the AI did it" is not an answer. "Chase approved it without the disk check" is, and it tells me which instructions to fix.
